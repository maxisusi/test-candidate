### Contexte

On travaille sur une petite application « Annuaire » d'une équipe RH. L'application liste les employés et affiche des statistiques par département. Le code a été récemment modifié par un·e collègue, et plusieurs comportements ne fonctionnent pas comme prévu.

Ton travail consiste à identifier les anomalies et les corriger.

### Comportement attendu

Onglet Annuaire

- Un tableau liste tous les employés avec les colonnes : ID, Prénom, Nom, Département, Manager.
- Un champ de recherche filtre les employés à travers les différentes colonnes (au fil de la saisie, avec un léger délai). La recherche est effectuée côté backend.
- Une case « Épingler en haut » place l'utilisateur courant en première position de la liste.

Onglet Statistiques

- Un tableau affiche, pour chaque département, le nombre d'employés correspondant.

- Durée indicative : 30 min max.
